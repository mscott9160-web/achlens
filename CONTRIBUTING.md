# Contributing

Install development dependencies with `uv sync`, then run the quality checks
listed in `README.md`. Keep foundation changes small and use synthetic data
only.

## Support and Triage

Use the repository's GitHub issue forms for reproducible bugs and usage
questions. Search existing issues first, include the project version and
operating system, and remove all real payment data before submitting anything.
GitHub Security Advisories are required for suspected vulnerabilities; do not
use a public issue for security reports. See [SECURITY.md](SECURITY.md) and
[the support expectations](docs/support.md).
